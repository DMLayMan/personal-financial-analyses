## 与0.2结果的差别

旧测试包含“引用任意核验事实后缺口关闭”的错误期望，本轮已纠正；不是为维持测试通过而隐藏行为变化。旧验收脚本也曾在银行必需模型失败时仅因文件哈希正确而exit0，现改为必需产物失败即失败。

新反例主要验证阻止错误的能力。公式代数勾稽、通用参数敏感性或软件流程仍不能证明盈利承保、因果解释、有效反方、当前定价或选股效果。六家及候选题都是公开开发材料，没有独立专家盲测结果。
