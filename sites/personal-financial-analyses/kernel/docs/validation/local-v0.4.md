## 市场取数实际结果

最后一次显式刷新中，13个外部序列成功自动读取：9个Yahoo指数/波动/FX/期货，4个FRED收益率/信用/现货CSV；另派生1条同日10年−2年曲线，共14个有效观察。当前最新快照没有使用人工转录；早期页面转录和失败尝试仍保留。其余11项是待接入目录，均无虚构数值。

恒生科技及沪深300本次路径各只有1个有效观察，没有计算涨跌或绘制虚假走势；其他所选序列有效观察122–150个（逐系列详见记录，窗口和频率并不完全一致）。价格指数不当总回报，Brent现货与近月期货不拼接，外汇定盘不混用。

四个FRED序列各抽查页面转录的5个日期与CSV匹配。属于同一提供者两条读取路径的核对，不是独立经济证据或完整历史审计。标普/VIX另抽查FRED页面日期与供应商观察，按页面公布的小数精度一致；未逐日独立核对全部行情。没有持续运行或生产授权承诺。

## 审查中真正发现并修复的问题

| 问题 | 修复前证据 | 修复及回查 |
| --- | --- | --- |
| 管理层说法进历史实际表 | 隔离库将已转录核验的公司说法设独立口径，报告错误纳入 | 报告只选择适用历史实际类型且满足公开/期间时点；反例通过 |
| 错标识行情 | 模拟返回其他symbol，读取器原先接纳 | 校证券标识与品种，拒绝错误响应；反例通过 |
| 市场原件漏备份 | 备份恢复后市场原件缺失 | 原文与市场响应均归档校验；隔离恢复反例通过 |
| 数值异常缺失败证据 | 只显示Decimal异常，无响应可核对 | 留存失败响应及SHA，提供可读错误；旧快照不变 |
| FRED空单元格当源故障 | 回看实际失败响应，有效CSV中空字符串被当数值异常 | 增加“空格为空值、不得补0”的预写反例并修复；4个FRED序列随后真实取数成功 |
| 报告具体页码打开首页 | 浏览器点击“PDF第93页”，实际第1/232页 | 传递原页参数；回查第93/232页成功。通用文档入口仍从第一页开始 |

未覆盖的失败方式仍需后续扩展，不因本轮反例通过称所有语义问题解决。

## 当前核心结论与下一阶段

三层信息架构、知识/方法入口、来源可得性和行业报告现在可以被用户实际检查；之前只靠公司卡片表达平台的问题已修正。研究效果的核心缺口没有由此消失：经营到实际/预测桥、资本与融资约束、参数依据、语义补证/最强反方、当前价格/共识及前瞻校准仍需单独推进。

下一阶段按已登记合同优先BYD资金与投入、CATL现金转化、CMB信用与资本，再完善微软AI、Costco会员与腾讯投入/投资价值。每项先固定原文答案与独立算术反例，再实现能真正改变预测或限制结论的机制。付费数据、远程部署和账户动作仍不在本轮范围。

交付前已创建本地完整备份并恢复到临时新目录：72个文件均校验，含35个市场原始响应/转录文件；SQLite完整性为ok。该演练验证归档/恢复与字节一致，未声称完成另一台机器的运行恢复或跨设备部署。
