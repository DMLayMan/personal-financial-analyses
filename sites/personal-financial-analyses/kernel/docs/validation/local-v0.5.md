## 发现并修复的实际问题

1. 宽度断点曾把三个主入口移到顶部：现在跨断点固定左栏；三组实际视口检查通过。
2. 仅按当前市场值比较会漏掉前值修订：预写反例复现后，将前值/日期/变化及来源状态纳入依赖。同值重复取得不因新快照ID而制造经济变化。
3. 全局信息列表截断可能漏掉公司的较旧但仍相关提交：单独按公司获取，反例用150条宏观噪声验证不会掩盖公司记录。
4. 平台建设/GICS来源不应出现在个股估值方法中：限定适用范围，SVB仅银行适用；保留反例。
5. 信息原件变化需暴露：元数据原件哈希失败时标为不可核，不能继续保持普通待审状态。信息元数据始终不进入财务事实表。
