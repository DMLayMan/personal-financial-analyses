# 市场与信息看板研究合同

版本0.4，2026年10月25日。市场数据服务研究背景与暴露检查，不能直接将大盘方向映射为公司评级。用户要求看板覆盖大盘、重要数据与信息源；实际覆盖和读取失败应与指标同屏。

## 单位、时间和缺失规则

- 收益率/信用利差保留百分比水平：5.13%→4.96%是−17bp。10年−2年先对齐日期，再乘100得到bp。不是−0.17%的相对跌幅。
- 指数/FX/油价变化为相邻有效记录的相对百分比；VIX变化用指数点。记录中间缺失时，不跨过缺失去伪造“一日”变化。
- 观察日期按交易所/供应商时区转换。未来日期排除；空单元格/“.”不是0；没有前值则显示不能比较。日内观察可能尚非最终收盘，界面明确提示。
- 观察日、供应商发布/修订、实际取得与最近尝试分别保存；有取得日不代表已取得今日观察。时效阈值是保守目录条件，未接各地完整节假日历，不把周末一律当故障。
- 当前取得的历史并不是历史时点可知数据。FRED修订、指数成分存活与期货换月未实现无前视回放，不能直接拿本版历史声称策略回测。
- 快照响应保存原件校验值；完整性失败时停用该快照数值。哈希只证明一致，原文含义和转录仍需语义核验。

## 解释和提醒

按“观察→冲击原文→净暴露→时滞/抵消→财务桥→预期差”处理。利率下行可能降低折现或资金成本，也可能反映需求风险；人民币贬值可能利出口，但海外成本/债务/套保可抵消；锂价下降可能压电池收入同时短期改善毛利，取决于合同和库存。因此提醒应打开研究问题，不直接宣布利好/利空。

首版目录含研究关注阈值：权益一般2%/恒科3%，利率或信用10bp，VIX3点，FX1%，Brent5%。这些是显示/交互的起始条件，**未经统计或前瞻校准**，不是显著性、经济重要性或止损标准；需结合观察日期和来源失败状态。未来应按公司暴露、持仓风险和事件噪声逐项校准，而不是统一“大盘风险总分”。

公司已有两类实质现金监测继续保留：CATL累计与单季CFO勾稽，腾讯报告与调整FCF对照。宏观变动尚不会自动重算个股盈利模型；公司参数更新前必须有暴露与财务桥。缺指数行情不代表公司财报不可研究；缺公司暴露则限制宏观对个股的量化结论。

## 来源与读取办法

| 来源 | 读取方法 | 当前可用性/边界 |
| --- | --- | --- |
| [FRED DGS10](https://fred.stlouisfed.org/series/DGS10)、[DGS2](https://fred.stlouisfed.org/series/DGS2) | 页面原文及CSV请求 | 页面及CSV本次核对；失败尝试单独记录，当前历史非初值库 |
| [FRED HY OAS](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 保留ICE BofA原始定义 | 百分比水平，非单家公司资本成本；历史可得长度受源条款制约 |
| [FRED Brent现货](https://fred.stlouisfed.org/series/DCOILBRENTEU) | EIA转发日度 | 有发布滞后；不与近月期货拼接 |
| [Yahoo Finance](https://finance.yahoo.com/) | 选定公开图表JSON | 延迟/盘中观察、接口和授权不作生产承诺，失败可见 |
| [人民银行](https://www.pbc.gov.cn/)、[CFETS](https://www.chinamoney.com.cn/) | 官方数据/公告入口 | 系列、期限与发布时间的稳定接入待做 |
| [国家统计局](https://www.stats.gov.cn/)、[BLS CPI](https://www.bls.gov/cpi/) | 原始发布及修订 | 目录阶段；尚无一致预期/发布日历或历史初值覆盖 |
| [香港金管局](https://www.hkma.gov.hk/) | 流动性/利率/统计 | 目录阶段，需确认字段、日历、频率和使用范围 |

证券市场主数据、价格、经济初值、共识和授权研报应分别采购/核验。当前没有买入Bloomberg等终端或投行研报，不以公开产品介绍冒充已读付费研报。

## 更新与扩展验收

页面按钮创建持久化市场刷新任务，独立于公司原文任务；成功追加快照，失败保留历史。仅服务运行时处理，没有启用每日定时任务。可用`scripts/refresh_markets.py`手动更新，转录导入须明确方式并保存源URL/取得信息。

新增源先固定指标ID、单位、时区、数据拥有者、频率/滞后、修订/授权和传导问题；用原文与独立算术验证小样本；测试缺失、不同日期、失败、单点、原件变化与未来值；再接仪表盘。来源健康与研究有用性分别评价。
