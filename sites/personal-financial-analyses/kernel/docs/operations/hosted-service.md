# 私有远程工作台方案与验收合同

用户在2026-10-25明确要求其他地点可访问，远程部署已纳入本轮范围。站点默认仅本人登录；不改变为公开。

## 架构决定（实施前）

现有研究内核依赖Python Decimal、SQLite和PDF原件。Sites托管使用Cloudflare Workers JS入口（128MB），并非现有HTTP服务的直接宿主。采用Vinext服务端承接身份、同源请求和持久化；浏览器Web Worker内以固定版本Pyodide执行同一套Python模块。金融方法、事实核验、缺口、反方和报告版本均复用源代码，不另造一套JS估值公式。原件存私有云，浏览器工作内存加载后逐文件核哈希。

云端只持久化个人研究空间；SQLite一致性快照不可变保存，当前版本用D1比较并交换，原件按SHA寻址放R2。先上传原件再提交数据库；多设备写冲突返回409，旧版本保留，禁止静默覆盖。成功提示只能出现在云端提交完成后。私有身份由Sites提供，不造另一个登录系统。浏览器执行不是外部AI，也不是独立金融审查。

## 预先验收

1. 未登录者不能取研究数据库或原件；跨站不能修改；源码及归档不含凭据。
2. 两个客户端同时以旧版本写入只能成功一次；错误、空响应、过大响应不能提交为成功。
3. 关闭页面后重新加载，知识/事件/报告版本仍存在。原件缺失或篡改不能显示核验通过。
4. 六公司实际事实、报告、示例模型与本地同内核输出核对；计算不得改用浮点近似。
5. 公共资料与行情刷新走受控HTTPS白名单与受限响应；不变成任意URL代理。未读标题不进入事实。
6. 手机布局可读；初次内核加载显示进度及失败重试，不无限空白。
7. 站点原生部署状态成功才报告上线；保存云端版本、源码提交及测试证据。

## 明确边界

研究计算在打开页面时运行。站点可以离开本机访问，但本轮不提供页面关闭后的连续监控或自动分析。首次加载需要下载Python运行时和证据包；实际大小、延迟及移动设备体验待实测。云端与本地为有版本的分支，首次导入后不做无提示双向同步。私有仅本人访问；后续共享需另定权限。投资级行业预测、当前公允价值和独立反方充分性仍未通过验收。

## 外部技术依据

- Sites随插件提供的托管、身份、D1/R2合同（本机已读）。
- [Cloudflare Python Workers机制](https://developers.cloudflare.com/workers/languages/python/how-python-workers-work/)与[标准库边界](https://developers.cloudflare.com/workers/languages/python/stdlib/)：Python Workers虽可用，但Sites归档要求JS入口；不能以Cloudflare通用能力推定此托管接口支持Python入口。
