# Fxx 功能名

- 用户决定与收益：这项功能如何改善具体公司的研究或核查？
- 当前范围与允许用途：适用行业、市场、期限；明确排除哪些用途。
- 输入合同：字段、定义、来源、公开时间、期间、币种、范围、版本、缺失处理。
- 分析逻辑：业务→财务→估值/风险；主假设、替代解释、什么会推翻判断。
- 输出合同：事实/解释/预测/假设、来源、缺口、准备程度、下一验证。
- 失败方式：列足以造成错误决定的反例，不只列页面异常。
- 资料与标准答案：原文定位、外部方法、独立计算；答案谁裁定、是否已用于开发。
- 验证方法：单元、集成、真实原文、语义审查、保留集、前瞻或运行检查分别说明。
- 通过门槛：事前写出；哪些由程序判断、哪些需研究者裁定；无证据就不晋级。
- 实际执行：命令、版本摘要、用例ID、结果与证据文件；未运行不得写通过。
- 剩余限制与下一步：负责人角色、来源缺口、失效/重开条件。
- 状态：计划 / 实现 / 功能通过 / 方法评审 / 前瞻校准，分别记录。
