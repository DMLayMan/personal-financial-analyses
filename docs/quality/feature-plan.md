## 实施顺序

1. 本轮先完成F01及已复现控制缺陷，保存反例与真实访问证据。
2. F03先从现有原文补齐关键经营及正常化字段，区分未提取和尚不可知。F04/F08同时建设语义评审标准；不能仅因文字更多就提升结论。
3. F05/F06/F07按六公司逐项建立驱动与预测桥：优先比亚迪资金/投入、宁德现金转化、招行信用/资本，再落实微软、Costco、腾讯。每家完成一条正确传导并验证，再扩大模板。
4. F09补时点、证券主数据与价格预期后，才评价现价经济性；F11保留集和F12前瞻按预写方案积累。付费数据与远程部署仍待用户确定范围。

## 六公司功能拆解

| 子项 | 要实现的功能 | 预先定义的验收 |
| --- | --- | --- |
| F05-Microsoft | GAAP→OpenAI投资损益/税→审议后正常化；租赁与现金投入桥 | 原始/公司调整/自有调整分别存；调整不重复；云增长不得直接推AI回报 |
| F05-Costco | 会员结构与滞后续费、提费现金与递延确认 | 从已取得10-K提取并保留7–18个月滞后定义；收费时间与收入确认区分 |
| F05-Tencent | AI预付款、资本承诺与业务回报；投资/回购 | 剔预付款的指标不能使真实付款消失；投资价值与收益避免双计 |
| F05-BYD | 车型/地区量价成本、营运资本、Capex融资与普通股桥 | 同销量不同ASP/成本应使利润不同；资金缺口不能被利润分配假设掩盖 |
| F05-CATL | GWh/ASP/材料传导、票据应收预付、产能回报 | 9M与单季同时核验；现金冲击有可解释的资金桥、时滞与反证 |
| F05-CMB | NIM/NII→信用成本/费用/税→普通股净利；RWA/CET1分配 | 息差、信用或资本压力须改变适用预测或显式暂停；不得仍给无约束同值 |

每项通过后记录命令、源码摘要、题目、实际结果和剩余限制。尚未执行的方法、保留集、专家审议或前瞻评价明确写未验证，不生成装饰性质量总分。
