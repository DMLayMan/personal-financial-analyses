# Personal Financial Analyses 本地首版

版本：0.5.0。日期：2026年10月25日。当前研究质量判定及限制见[自查报告](quality/review-2026-10-25.md)。

## 启动

需要Python 3.9或以上；本次实际验收使用Python 3.12.14。首次安装：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./scripts/start.sh
```

打开 `http://127.0.0.1:8765`。脚本启动独立后台服务；用 `.venv/bin/python -m pfa.service stop` 停止，status查看状态、doctor检查页面、restart重启加载代码。需要前台调试可用 `.venv/bin/python -m pfa.server`。首启建立SQLite数据库并导入六家公司的公开取证包，已有数据库不会重复导入或覆盖用户记录。页面适配窄屏；手机异地访问仍待部署阶段。

本工作区已经配置 `.venv`，可直接运行启动脚本。原件与数据库在 `data/`，不进入Git。新克隆仅带取证元数据与选定条目，需要通过原文链接重新获取本地原件；不存在原件时会明确提示。

## 三层入口

默认首页为平台与研究基础，包含理论/工作流、Agent职责合同、知识文档、审查和扩展。市场页含大盘指标、来源状态、缺失/滞后及行业通道；公开获取按钮入持久队列，当前没有定时监控。行业页按四组/六类机制筛选，公司默认打开研究草案报告；原有六步操作保留。

运行 `.venv/bin/python scripts/refresh_markets.py` 显式更新选定公开序列。部分来源失败会返回非零并保留旧快照；查看页面的观察日期、模式和失败状态。新克隆没有市场数据时显示缺失/目录，不伪造初始化行情。人工页面转录可用`--import-transcription /绝对路径/文件.json`，输入包含`series`数组，各项含`id/source_url/points/note/source_updated_at`，原件不进Git。

市场背景不会自动改写模型或已发结论；七种Agent职责是当前规则/人工工作分工，外部模型和自主研究尚未接入。

## 当前可用流程

1. 在研究问题页读取、修改主假设、最强替代解释和经营到财务的传导，保存新版本。
2. 从白名单公司或监管原文HTTPS地址安排获取。持久队列在服务运行时处理，有去重、失败、人工重试与中断恢复，总计不超过三次尝试。下载原文不自动核验事实。
3. 在资料页按原文页码或HTML锚点提取候选，记录期间、元单位、合并范围与会计口径，再核验或撤回。PDF文字提取仅辅助定位，复杂表格应回看原始页图。
4. 查看同口径冲突、关键经营未知和监测触发的补证队列。记录下一来源、继续或停止理由；补证回应必须关联当前可用核验事实。0.3不再因引用存在就自动关闭经营未知，回应保持待相关性和充分性审查。
5. 在已核验输入上运行盈利和估值。非金融企业使用年度收入、净利率、增长、分配与终值PE情景；银行使用合并普通股权益和剩余收益模型。三种情景均保留公式、参数、输入和来源。
6. 写最强反方、实质回应、可观察推翻条件，至少引用一条已核验依据，再形成条件结论。反方可以使主假设失效。旧结论保留，新资料、核验撤回、研究假设、补证处理或新模型会要求重新审查。
7. 在结论页记录新事件的暴露、传导、时滞、未知与下一验证；导出完整研究JSON查看依赖和历史。

## 估值与判断边界

默认参数是明确标记的敏感性起点，未由历史统计校准。非金融企业模型是盈利与分配假设的股权价值情景，不冒充完整三表、FCFE/FCFF模型或现价目标。分配比例尚未证明为可支付现金；PE终值亦需研究。

报告归属净利用于经营诊断。存在同期间、同口径已核验的普通股或EPS勾稽利润分子时，估值另用该分子并单独列输入，避免忽略永续债、限制性股票或稀释调整；两种利润不合并，也不将EPS分子称为正常化利润。不存在该分子时使用报告归属利润并保留权益归属限制。

银行模型保持普通股权益与净盈余关系，终值留存和增长勾稽；尚需研究OCI、其他资本变化、信用成本与监管分配约束。

所有情景折现起点为所选基线报告期末。首版未将报告期末至今日的实际与预测滚动衔接，不能称当前公允价值。最近中期数据单独进入诊断、现金流监测与补证，不乘二冒充全年。

当前没有可靠证券现价、完整外币转换及历史一致预期，结论保留证券经济性缺口。没有账户输入，不生成个性化仓位。可信度分别表达核验状态、解释、估值假设和准备程度；未提供上涨概率。

AI服务未配置。应用使用确定性规则、公开原文和研究者分步审议；不会伪称由独立分析团队完成。初始六家条件结论标记 `implementation_acceptance`，是流程验收与研究者意见记录，尚未经用户独立审议。

## 验证与可恢复性

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/quality_gate.py --live
.venv/bin/python scripts/validate.py --db data/acceptance-new.sqlite3 --output data/acceptance-new.json
```

验收脚本要求新的数据库路径以保留上次记录，在隔离库执行六家完整流程并核对原件SHA256。原件缺失时不会声明完整通过。测试覆盖冲突、候选隔离、撤回、旧结论失效、反方推翻、补证重开、银行适用性、计算关系、失败任务、HTTP修改与备份恢复。

```sh
.venv/bin/python scripts/backup.py backup data/backups/research-001.zip
.venv/bin/python scripts/backup.py restore data/backups/research-001.zip --destination data/recovery-001
```

备份包含数据库一致快照、公开原件和校验清单；恢复到新目录并核对内容与数据库完整性。恢复后可将 `data/recovery-001/data/` 复制到新的同版本工作副本。备份也需保存在个人可控位置。

0.3补充了研究质量判定、事前功能合同与反例。当前下行情景、关键口径、补证充分性与运行交付须分别验收，详见[功能计划](quality/feature-plan.md)及[运行手册](operations/local-service.md)。

## 知识、信息与报告更新

知识页可新增/修订/停用参考，保留历史；草案不替换采用版本。来源URL仅是参考，不自动成为已接入数据源。公司报告记录采用版本，差异需复核。

市场页“公告与政策信息”按需获取Fed RSS和选定SEC公司提交记录；标题和元数据需回看正文，可以手动关联待核查事件。当前没有持续实时推送或港A完整公告流。

公司“研究报告”先展示证据判断链及预测估值门槛，再展开原有全部资料/操作。可保存研究草案快照、下载旧版；“打开独立报告”路径为`/reports/{公司ID}`，另可下载HTML。信息原件在`data/information/raw`，与DB、原文、市场原件一起纳入本地备份。
