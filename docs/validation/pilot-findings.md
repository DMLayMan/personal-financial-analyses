# Personal Financial Analyses 样本验证记录

版本 0.1
样本资料截止 2026年10月25日

本轮选择六家公司检验数据获取、口径、事件传导、敏感性和提醒需求。以下保存对话中的设计发现，不重新发表个股评级，也不把它们描述为完整首次覆盖报告或预测绩效验证。

原始取数日志主要存在于本会话；本仓库保存验证摘要与来源入口，尚未形成完整可重放的数据包。此前下载的第三方原件保留在本地来源目录，未纳入 Git。

## 样本与发现

| 样本 | 验证内容 | 导出的设计约束 |
| --- | --- | --- |
| Microsoft MSFT | 云增长、现金投入、租赁及折旧分类、公司调整盈利 | 资本开支、经济投入与现金流分开；调整EPS需要勾稽 |
| Costco COST | 会员费确认、月度销售、日历因素、一次性收益及财报版本 | 经营频率不同不能直接拼接；快报与后续版本均留存 |
| 腾讯 0700.HK | 非IFRS利润、资本开支、现金付款、预付款与净现金 | 同名或相近指标保留公司定义；不单凭调整FCF判断 |
| 比亚迪 1211.HK及关联A股 | H1与推导Q2、月度与累计产销、股本及币种 | 累计与单季分开，销量到盈利需中间机制，多证券一致映射 |
| 宁德时代 300750.SZ及关联H股 | 合并现金流累计转单季、毛利与资金占用 | 原始精度计算，保留管理层解释与后续验证，不将累计稳定当单季稳定 |
| 招商银行 600036.SH及关联H股 | NIM、净利息收入、信用成本、资本和普通股净资产 | 银行专用模板；集团与母行、资本方法和普通股口径分开 |

各报告入口见[数据源与验证状态](../data-sources.md)。

## 需要保留的反例

1. 比亚迪搜索摘要曾将下降抽取成增长。回看原PDF关键页后，原文叙述和财务表一致。异常来自搜索或抽取路径，不能指称公司原文出错。
2. Costco业绩公告与后续10-K存在小额现金流版本差异。应采用适用的新版本并保留旧值，不能把不同版本拼接，也不应将所有微小修订都推送为重大投资提醒。
3. 宁德时代单季现金流需要用未舍入合并原值相减。使用已展示的舍入值可能得到不同末位结果。
4. 某些公开行情页的搜索结果、正文时点或派生指标口径不一致。能够验证收盘字段，不代表整页财务倍数都可直接使用。
5. SEC companyfacts同一指标可能来自不同表单与期间。不能只按最新filed时间拿一个值当作指定年度10-K数字。

## 验证结论

公开原始材料可以支持第一版研究流程。统一API不能假设覆盖全部经营KPI；数据可读、字段核验、持续更新与使用权限分别管理。

事件到盈利的量化需要具体暴露、转嫁、时滞和反方解释。缺输入时展示有明确假设的单位敏感性，并限制结论。静态倍数和假设敏感性不等于完整预测估值。

## 尚未验证

- 全部行业的深度研究能力和完整三表、估值模型。
- 事件发生前的一致预期和所有历史初始版本。
- 稳定更新、数据恢复、生产许可和外部展示。
- 前瞻预测校准、超越基准方法及投资结果。
- 失败与退市对象的完整历史回放。
- 个人账户适配、仓位、成本与交易执行。

## 后续验收方式

将这些发现转为需求文档中的AC场景。先检查规则在预设异常下的行为，再登记真实前瞻研究并结算。六家大型持续经营公司的成功读取，不能单独证明风险识别或选股有效。
