## 链路验收

每家公司均执行：资料与选定字段核验 → 经营未知与补证计划 → 冻结年度或普通股基线 → 三情景计算 → 有具体内容的反方、回应及推翻条件 → 条件结论。所有情景参数仍标为未获用户审议，结论明确保留现价、共识和账户约束缺口。

初始结论的反方内容由开发时研究者编写，记录为 `implementation_acceptance`，界面可见；不伪称用户已确认或获得独立机构复核。独立数据库验收报告保存在本地 `data/acceptance-report.json`；最终复验可用运行指南命令生成新版本。

两项实际规则触发：CATL同口径9M减H1，单季CFO同比显著下降；腾讯同期间报告FCF为负而排除预付款后的指标为正。触发后保留计算输入、规则、潜在解释及下一来源，不直接转化为交易信号。50%的CFO下降阈值属于未校准的初始研究筛查规则。

## 异常与恢复

自动化场景覆盖候选不能直接进模型、冲突不平均、关键银行权益撤回后暂停估值、资料及模型变化后旧结论失效、反方使结论撤回、补证依据撤回后重开、并发修改冲突、原件篡改、有限重试与恢复、CSRF/Host检查、数据库及原件备份恢复。

22项自动化测试全部通过。六家独立库验收全部生成三情景、反方与条件结论，12/12份原件SHA256匹配；本地机器结果为 `data/acceptance-v02.json`。

浏览器已实际检查工作台与重点现金流提示，并在Costco完成模型重算 → 旧结论失效提示 → 反方审查 → 第二版条件结论，第一版仍保留。宁德时代Q3本地PDF共13页，已实际读取正文。截图保存在 `artifacts/local-v0.2-research.png`（不进入Git）。响应式样式已实现，本次未完成真实手机或窄屏模拟验收。
