# Personal Financial Analyses 数据源与验证状态

版本 0.1
记录日期 2026年10月25日

这份清单记录本会话已做的读取验证和方案中的候选来源。它不是全部接口已经接通的声明，也不替代数据供应商的覆盖、历史和授权验收。

## 能力状态

每个来源按以下维度分别记录。某项通过不会使其他维度自动通过。

| 维度 | 通过所需证据 |
| --- | --- |
| 入口定位 | 有准确URL、接口或文件位置 |
| 正文或数据读取 | 实际返回可用正文、JSON、表格或原始文件 |
| 字段提取与核验 | 关键字段与原文、单位、期间和计算一致 |
| 持续更新 | 重复运行、异常、延迟、重试与恢复经过验证 |
| 历史可用性 | 能取得当时信息集、修订与历史标识；范围已确认 |
| 留存与展示 | 存储、模型使用、个人展示和对外展示的权限分别明确 |

## 规划中的来源类别

| 类别 | 用途 | 当前接入状态 |
| --- | --- | --- |
| 公司与监管原始披露 | 财务、重大事项、治理和资本配置 | 部分路径已读取，生产接入未完成 |
| 行业与关系方资料 | 供需、竞争、客户及供应商验证 | 按研究问题选择，未建立稳定覆盖 |
| 标准化财务 | 跨公司比较与模型输入 | 商业供应商未连接和验收 |
| 一致预期与历史快照 | 预期差、分歧与修正 | 未取得可用的授权历史共识集合 |
| 宏观与政策原文 | 外部事件与行业暴露 | 个别原文已查阅，未建立生产订阅 |
| 另类数据 | 验证经营假设 | 尚未采购或接入 |
| 用户研究与持仓 | 原有判断、个人组合和约束 | 用户尚未提供；不阻塞公共公司研究 |

供应商选择根据关键字段、覆盖、时效、历史、权限、可靠性和费用决定。Bloomberg、LSEG、FactSet、S&P、Wind等只是候选，不因出现在文档中就形成采购决定。

## 生产接入前的逐项检查

每项来源需确认字段主来源和备用路径、市场与历史范围、公开时间定义、公司行动、口径字典、重复与修订处理、频率与限额、失败恢复，以及实际允许的留存和展示。

首次生产运行前保存有时间的读取记录，并验证计划中的正常更新周期和失败恢复。具体运行时长与时效目标在来源和部署范围确定后制定。

历史API数据只有在满足当时可得和版本条件时，才能标记为可供历史回放。监管原文、数据商和媒体的相同上游记录不能算作独立证据。
