# 报告内核、信息接入与长期迭代

> 阅读入口（2026-10-27）：本文为0.5报告设计基线；当前统一报告合同与实现边界见[详细PRD](platform-design/PRD.md)和[技术方案](platform-design/TECHNICAL-DESIGN.md)。

版本0.5，2026年10月25日。沿用三层：平台知识方法、市场与信息、行业公司报告。三个主入口始终在左侧；窄屏使用左侧紧凑栏。公司快捷入口只在第三层出现，首页不再重复三张导航卡。

## 产品重心与现状结论

第三层是核心研究产出。前两层必须成为可追踪输入，而非与报告无关的展示页。当前可落地的是已报观察、证据判断链、方法/数据依赖、缺口门槛和报告版本；尚未完成六套行业经营预测、现价证券估值、独立语义审议和前瞻校准。

每条判断分开保留：观察到什么、读取哪些事实、用何种方法、经营机制、财务影响、估值影响、最强反方和下一证据。可以计算的同口径实际变化用Decimal；从历史变化到未来持续性及公允价值之间的未知不能由模板补齐。

报告输出分为证据研究更新、经营预测更新、证券估值/投资意见等不同用途。本版只允许前者和原有示例敏感性。保存报告不改变用途；采用某方法也不代表方法或预测已经得到验证。

## 第一层怎样持续更新

内置公开参考以Git管理；本地增加/修订/停用知识以SQLite不可变版本保存。每项有稳定标识、正文、类别、来源、适用公司/行业、条件/失效及变更理由。用户可以在知识页修订，保留历史。

- 草案不替换正在采用的版本；“纳入本地参考”只表示个人采用，`method_validated=false`由后端固定。
- 采用版本进入对应报告的依赖。修订、停用或适用范围改变后，已存稿显示方法依赖变化。
- 知识文本改变研究提问和参考，不直接执行任意公式或自动改变财务参数。新增计算规则需代码、原文/独立基准及反例验收。
- 个人改编与内置原文分开，方法有效性、来源正确、采用状态分别评价。

行业手册继续按经济机制组织。新增公司需要核身份、行业与适用方法；未映射行业时显示缺口，不复制已知六家模板或抛出无解释错误。新增行业驱动仍需字段字典、资本/融资桥和独立验收。

## 第二层：真实接入程度

| 能力 | 当前实现 | 不能据此声称 |
| --- | --- | --- |
| 公开市场数据 | 13个选定外部序列按需读取，另有同日曲线；观察/取得/失败及原件 | 全市场实时、所有交易所授权、秒级推送或持续可用 |
| 美联储 | 官方RSS元数据，发布时间与首次取得分开 | 所有政策、全部正文或自动经济解读 |
| SEC选定公司 | MSFT/Costco提交元数据，核CIK，筛10-K/10-Q/8-K/股东材料 | 新公告已读懂、自动财务核验或全部美股覆盖 |
| 港A与授权信息 | 现有原文获取及来源目录 | 已完成公告流、实时新闻、共识与行业全覆盖 |
| 事件关联 | 用户明确说明关联、机制、未知和下一验证后登记公司事件 | 标题自动变成利好/利空或盈利参数 |

[SEC API文档](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)说明上游在提交披露后更新；本应用当前按需拉取，不把上游发布频率当成本地送达频率。[Fed RSS目录](https://www.federalreserve.gov/feeds/feeds.htm)提供公开源入口；取到元数据仍需阅读、判断相关性及正文核验。

更新模式应固定为人工导入、按需请求、定时轮询、推送等明确类型。当前是按需请求，没有悄悄启用常驻定时或消息通知。未来若接入授权行情，需验证市场/品种、覆盖/延迟、权限、交易日历、断线恢复和使用范围；工具里存在连接不等于网站后台已配置该连接。

信息任务与原件任务、市场任务分开消费；来源失败不清空既有记录。去重与未来时间/错CIK/外站链接控制先于扩覆盖。信息元数据不会进入财务事实表。

## 第三层：报告如何得出及更新结论

1. 读取当前核验台账、行业手册、采用方法、模型/反方/结论和市场观察。
2. 检查口径、期间、首次公开和冲突。对可比实际计算变化，同结束日的累计与单季分别保留；不把中期年度化。
3. 将现金监测置于收入增长之前综合呈现。现金异常不被收入增长掩盖；报告净利不自动代表正常化经营利润。
4. 每条观察列事实ID、公式、机制、财务含义、估值尚不能推导的部分和下一验证。
5. 当前市场通道为条件背景。缺公司净暴露、对冲、时滞与合同传导时，不编造利润变化。
6. 检查较新公司提交记录，提示回看正文和更新事实。登记事件不等于完成核验。
7. 核预测、证券价格/股数/FX、预期差和反方门槛；缺失则保持未评级、无目标价。
8. 保存研究草案快照及修改原因；导出可独立阅读的HTML或结构化记录。

当前证券价格、预期与独立反方门槛明确未完成；没有隐藏的“勾选即可解锁评级”。相关能力开发并验证后才修改规则。

## 版本与依赖

报告快照包含当时的正文、方法版本、原文输入、市场来源和依赖摘要，不覆盖旧稿。比较五类依赖：公司证据/模型/结论、采用方法、市场观察、事件/待读提交、行业手册。

市场依赖比较当前及前值/日期、变化幅度、有效性、时效与来源状态，而不是每次取得时间或新快照ID；同一观察重复抓取不产生经济变化。方法版本或新事件会提示复核，不自动宣称盈利已经改变。变化后用户要说明保留/修订理由，再保存下一版。

读取与保存检查审计序列和依赖摘要；页面过期或保存中发生更新则拒绝覆盖并要求刷新。保存报告写独立审计空间，不因为“保存”自身使公司模型或原结论失效。

## 扩展与评价顺序

优先按公司做真实驱动：BYD量价/现金投入融资、CATL单位盈利/营运资本、CMB息差信用/资本分配，再完善微软AI经济投入、Costco会员/门店、腾讯预付款/投入与投资资产。每个参数保留来源，增加有辨别力的压力反例，连到预测与普通股。

然后补证券身份/价格/FX和预期差；再扩港A公告、行业与授权新闻。独立语义与未见/前瞻评价单独进行。工程门槛、原文正确、方法有效和投资效果分别报告，不生成综合成功分。
