研究规程版本 1.0
项目文档基线 0.1
日期 2026年10月25日

本文件将此前Word规程保存为可审阅和修改的文本基线。规程规定研究方法；用户原始要求见[需求文档](requirements.md)，实现结构见[方案与技术设计](solution-design.md)。原有Word作为历史快照保留。

这份规程规定平台如何提出问题、读取证据、形成解释、补充信息、评价企业与证券、表达不确定性，以及在新事实出现后修改或撤回结论。它面向以中长期研究为主的个人使用者，首期覆盖美股、港股和A股。企业商业分析构成主干，证券估值与账户决策在此基础上分别进行。

本项目的核心判断是采用问题驱动的研究制度。研究从一个可能改变决定的问题开始，围绕竞争解释获取有区分力的证据，经过财务建模和反方审查形成有条件的结论。资料数量、报告长度和观点鲜明程度不能替代证据。

状态说明  本版完成方法与产品规则设计。此前六家公司完成的是公开取数、关键口径核验、事件传导示例和假设敏感性验证，尚未证明完整盈利估值能力、概率校准、账户适配或实际投资绩效。平台尚未实现，部分数据接口仅验证过单次读取。文中门槛和流程属于本项目设计，不代表任何投资大师或机构的内部规定。

## 一 平台服务的决定和研究边界

个人使用者需要一套能够长期积累判断的研究能力。平台应减少重复查资料和口径错误，把注意力放在少数能够改变商业判断、估值或风险承受能力的变量上。移动端承担变化提醒、核查和记录；深度比较与建模使用较大的工作界面。

同一家公司的经营质量、增长潜力、当前证券回报和适合个人持有的程度可能不同。任何结论都要说明对象、期间和比较基准。行业研究也可以独立存在，不必强行转成股票目标价。

| 判断对象 | 要回答的内容 | 完成所需条件 |
| --- | --- | --- |
| 企业与行业 | 如何赚钱 竞争优势 增长约束 资本配置 生存能力 | 业务机制可解释 核心事实与反证可追溯 |
| 事件与预测 | 新信息改变什么 在何时影响多大 | 有传导路径 明确假设与未知 有后续检验 |
| 证券经济性 | 当前价格要求什么 可能获得什么回报 如何损失 | 价格和权益口径一致 有完整预测或适当估值依据 |
| 账户决定 | 是否适合持有 规模与期限如何约束 | 了解资金用途 流动性 现有暴露 损失承受能力及成本 |

首期不宣称具备全行业同等专长。对会计、临床、技术、监管或交易结构存在决定性理解缺口的对象，转为需要专业复核的研究任务。未取得账户资料时，停留在公司与证券研究层，不能自动产生个性化仓位动作。

## 二 信息到决定之间的六种记录

平台应分别保存观察事实、待检验判断、因果解释、未来预测、估值与行动。它们通过来源和依赖关系相连，不能用一段流畅的摘要把边界抹平。

| 记录 | 示例含义 | 必须记录的边界 |
| --- | --- | --- |
| 事实 | 公司在某期报告了某项收入或现金流 | 原文 期间 单位 口径 公开时间 版本 提取核验 |
| 判断 | 增长主要来自真实终端需求 | 支持与反对证据 哪些观察可以推翻它 |
| 机制 | 订单如何经过交付 价格 成本影响利润和现金 | 中间环节 时滞 转嫁 抵消和替代解释 |
| 预测 | 明确日期前某项指标落入某区间 | 条件 期限 结算来源 信息截止点 校准状态 |
| 估值 | 在一组预测和资本成本下得到价值区间 | 预测版本 币种 股本 净债务 模型假设与敏感性 |
| 行动 | 补证 等待 放弃 复核或提出有条件投资建议 | 决策理由 替代选择 约束 失效条件 下一验证 |

公司指引作为管理层陈述保存；一致预期作为特定供应商在某时点的预测集合保存；股价隐含条件作为模型推断保存。原始文件可以可靠证明公司披露了什么，不能因此证明所有解释正确或未来指引必然实现。[S9]

## 三 研究状态和进入下一步的条件

每项研究从候选进入以下状态。缺一项条件时，限制对应层次的结论，同时继续可独立完成的工作。暂停、放弃和无法判断是合法产出。不能因为已经花了很多时间，就强行升级研究状态。

| 状态 | 必须交付 | 通过条件或处理方式 |
| --- | --- | --- |
| 明确问题 | 决定对象 期限 可选动作 重要性 | 问题可回答 并可能改变某项决定 |
| 核实证据 | 来源清单 核心财务与业务基线 缺口 | 决定性数字的实体 期间 单位和范围无未解错误 |
| 竞争解释 | 主假设 最强替代解释 各自预测的观察 | 知道什么证据能区分它们 |
| 建立模型 | 业务驱动到利润 现金和资本的关系 | 关系可解释 可复算 所有假设可见 |
| 情景与估值 | 下行 基准 上行 价格隐含条件 | 方法适合行业 关键暴露与价值依赖清楚 |
| 反方审查 | 最强反对意见 失败链 缺口处理 | 反方可能改变结论 并已得到实质回应 |
| 形成结论 | 分层方向 信心理由 准备程度 行动与条件 | 没有超出证据范围 不确定性进入决定 |
| 持续监测 | 验证点 新证据 比较与修改记录 | 只因相关证据或约束变化重开 不因价格本身确认逻辑 |
| 结算与退出 | 预测结算 过程复盘 覆盖退出或重入条件 | 保留失败与旧版本 区分过程错误和随机结果 |

一条基本原则是让结论受证据约束。没有可靠价格仍可完成企业经营分析；税基未知仍可展示每单位暴露的情景；缺少资金约束则暂不形成个性化仓位建议。

## 四 研究问题和竞争解释的写法

首次覆盖先研究商业模式、行业结构、正常化盈利、资本投入、治理及融资韧性，再明确值得长期跟踪的核心判断。事件更新只重开受影响的判断，避免每次重复生成整份公司介绍。

研究问题必须包含对象、期间、比较基准及决定用途。例如，研究未来两年利润率能否改善，需要明确改善相对哪一期、来自何种经营机制，以及它会改变预测还是进入价格。笼统的公司是否有前景不足以指导取数。

每个重要主假设应有合理的替代解释。收入增长可能来自销量、提价、结构、并购、汇率或确认时点。现金流转弱可能来自坏账、库存积累、供应商账期调整或预付款。列出假设后，分别说明它们预期哪些数据变化，优先寻找有区分力的观察。

因果判断按经济机制、时间顺序、暴露规模、传导时滞、抵消因素、同业或客户证据及替代解释逐项检验。股价与新闻同日变化只支持时间关联。对缺少反事实或识别条件的关系，使用有支持的解释或待验证机制，不能包装成已经识别的因果。

| 问题 | 区分解释所需证据 | 可能改变的决定 |
| --- | --- | --- |
| 需求真实增长还是渠道补库 | 终端销售 渠道库存 客户订单 退货与回款 | 收入持续性和库存风险 |
| 利润改善来自经营还是会计与一次性项目 | 分部利润 税率 投资收益 调整勾稽 费用资本化 | 正常化盈利和估值基数 |
| 投入是有回报的增长还是竞争性维持 | 增量收入 毛利 资产利用率 替换周期 现金承诺 | 再投资回报和自由现金流 |
| 便宜反映错误定价还是价值受损 | 正常化盈利 资产可实现性 债务索偿 稀释及风险情景 | 是否继续研究和可接受买入条件 |

## 五 信息源计划和读取规程

不从无限新闻流开始。先给每个决定性判断列出需要的字段、有效证据及主来源，再读取最小足够资料包。首次覆盖通常包括多年定期报告、最近一期结果及附注、分部与经营指标、资本和债务、治理与资本配置、同业和行业资料；具体跨度依周期和披露条件确定。

数据源分工采用原始披露确立报告事实、行业与关系方验证经营解释、授权数据库进行标准化及预期比较、研究和媒体提出线索的方式。主来源由字段决定。监管原文解释政策，企业披露提供暴露，行业资料不能替代企业合同。[S9][S14]

| 资料 | 优先路径 | 读取与验证要求 |
| --- | --- | --- |
| 财务与重大事项 | 公司IR SEC 交易所 巨潮原始文件 | API或HTML先取 复杂表格读PDF 必要时回看页图 |
| 经营与管理层解释 | 原始公告 电话会 说明会及正式纪要 | 保留问题和上下文 将解释与已报结果分开 |
| 行业与竞争 | 原始统计 监管 行业机构 同业及客户披露 | 检查样本 范围 方法 修订 产业链位置 |
| 价格与证券主数据 | 授权行情与公司行动资料 | 证券和币种准确 区分收盘 盘后 复权和交易日 |
| 一致预期 | 有权限的供应商及历史快照 | 统一年度 指标和调整口径 保存样本与快照时间 |
| 替代资料 | 有授权的流量 招聘 消费 地理等数据 | 核对覆盖偏差 与目标指标关系及数据稳定性 |

每条资料经历找到入口、实际读到、字段提取、口径核验、持续更新验证和使用权限确认六项检查。它们分别记录，不因为某次网页能打开就全部通过。读取失败时尝试合法的备用原始来源，并说明本次使用的路径；持续更新仍未验证时保留该状态。

本项目现有可用路径包括已实测的SEC部分JSON与美股行情，以及可读取的港股和A股原始文件。付费共识、全市场稳定接口、替代数据及再分发权限不能因被列入计划而视为已经接通。

## 六 证据质量和独立性

每项重要结论连接到证据，并记录上游出处、测量方法、发布时间、期间、实体、合并范围、币种、单位、定义、版本和原文位置。确定性计算保留公式与输入版本。对无法观测的变量保留未知，不按零处理。

多家网站转载同一公告不算多份独立证据；同一报告在A/H两地出现也不构成独立验证。独立性来自不同的观测路径、测量方法或利益主体，还要检查它们是否共享上游数据。审计财务数不需要机械地要求两个独立数据商重复，但关于需求原因或技术优势的解释需要更广泛检验。

来源质量取决于它能支持什么陈述。企业披露对已报告数字和政策有直接地位，对未来订单质量或产品优势仍可能存在激励偏差。对管理层、分析师、渠道、专家以及研究者自身，记录可能影响判断的利益和激励。[S3][S9]

| 异常 | 检查方法 | 处理 |
| --- | --- | --- |
| 来源数值不同 | 核对期间 单位 合并范围 修订及调整定义 | 保留两版 选值有理由 不直接平均 |
| 叙述与算术不同 | 重算同比 环比和勾稽 回看原页 | 暂停自动采纳 将摘要错误与原文错误区分 |
| 累计掩盖单季 | 用同口径未舍入原数相减 | 派生值带计算标识 不混母公司与合并数据 |
| 关键字段缺失或过期 | 检查发布时间 正常更新周期及获取状态 | 降低相应结论准备程度 设置补证动作 |
| 解释相互冲突 | 在共同事实下列出机制和区分证据 | 保留分歧 触发补证或人工复核 |

## 七 补证优先级和停止研究的条件

新增资料的优先级由它能否改变决定来确定。对每个缺口说明：可能改变什么动作；该变量的合理范围能否翻转动作或影响风险约束；什么证据能区分；是否能在决定期限前以合理成本取得。信息价值同时取决于结果可能性和后果，不能用下载数量表示。[S11]

当缺少税基、成本转嫁或客户集中度等关键输入时，先做范围分析。如果在可信范围内结论会从正面翻为负面，应优先补证；若关键数据不可得，就保留条件结论或暂缓。若所有可信范围都支持同一动作，可以带着已披露的不确定性结束本轮，并设重开条件。

资料之间高度相关时不能增加信心。一个关键现金履约缺口，不能被许多非关键正面指标平均掉。相反，存在多条独立且完整的证据路径时，可以说明结论在某一输入缺失时仍成立，而不能把所有缺失都等同于研究失败。

| 状态 | 下一步 | 交付状态 |
| --- | --- | --- |
| 会改变决定且证据可取得 | 优先查询原始记录 同业 关系方或授权数据 | 补证中 |
| 关键变量不可得且足以翻转决定 | 限定范围 等待指定披露或专业复核 | 尚不能判断 |
| 主要增加重复资料 | 停止重复搜索 保留来源依赖 | 本轮研究结束 |
| 可信范围内动作不变 | 记录稳健区间和剩余未知 | 可形成有条件结论 |
| 理解缺口无法解决 | 放弃或退出覆盖 设重入条件 | 超出能力边界 |
| 期限或预算到达 | 交付当前结论 缺口及影响 | 不得因此自动升级为可投资 |

## 八 商业判断和模型分析

商业判断先回答客户为什么购买、公司靠什么收费、利润由谁承担和分享、竞争者能否复制、增长需要投入什么资本，以及低谷时能否生存。护城河必须连接到定价、留存、成本或资本回报的可观察结果，并检查是否衰减。

预测由经营驱动产生，并勾稽收入、利润、现金、资产负债和股本。区分销量、价格和结构，区分投资、费用、资本化和折旧，区分受限现金、名义融资与可按时到账的资金。维持性投入难以准确拆分时给出范围，不能直接把折旧或EBITDA当作所有者收益。[S2]

行业模板按经济机制选择。银行以净利息收入、信用成本、资本、普通股回报和分配为核心；平台与软件需要留存、变现、单位经济和投入回报；制造业需要量价、产能、库存、营运资金和资本开支。新业务和研究驱动行业需额外的技术或专业证据，不能为了模板齐全生成未经验证的数值。

估值至少用适当的主要方法并做独立合理性检查。两种估值方法使用相同假设时不算独立证据。反向估值展示当前价格在给定模型下要求的增长、利润率和回报，不把反推结果声称为所有投资者的真实想法。

分别保存已报实际、公司指引、市场共识、自有预测和股价隐含条件。缺少可靠共识时仍可研究商业价值，但不能声称超预期。历史一致预期需要当时可用版本，今天的最新数据库不能自动用于过去。[S15]

## 九 投资思想如何进入研究制度

本项目采用可核查的原始材料建立方法库。大师思想用来约束问题和研究纪律；不能替他们生成对今天公司的实际判断，也不能把几个流派的赞成票相加成可信度。以下规则是本项目的制度化翻译。

| 思想与原始材料 | 转成的研究要求 | 适用边界 |
| --- | --- | --- |
| 巴菲特 能力圈与价格 [S1] | 解释业务和关键未知 检查买价要求 | 熟悉产品不等于理解经营 优质不能覆盖任意价格 |
| 巴菲特 所有者收益 [S2] | 核验维持投入 营运资金和可分配现金 | 估计本身可能困难 金融企业使用资本约束模型 |
| 芒格 多模型 激励与逆向思考 [S3][S4] | 检查激励 失败机制 替代解释和机会成本 | 自己的能力边界不等于所有人的行业禁区 |
| 格雷厄姆 低估与分散策略 [S5] | 单独规定资产或正常化盈利依据及组合规则 | 晚期组合法有特定背景 历史PE与收益率参数不能直接硬编码 |
| 彼得林奇 理解业务与生存能力 [S6] | 消费线索继续调查 扩张阶段和资金期限必须匹配 | 日常体验不能代替财务与渠道调查 |
| 霍华德马克斯 风险与预期 [S7][S8] | 研究永久损失 被迫出售 价格包含什么及自身差异 | 逆向本身不证明正确 波动仍可能造成真实持有风险 |

系统首先指定主要策略和收益来源，例如长期经营复利、周期正常化、资产折价或特定事件。不同策略要求不同证据和退出条件。不能以低估值买入，再在经营恶化时悄悄改用长期成长理由；策略改变须新建论点并记录旧论点如何失效。

本平台的默认研究取向是理解经营、资本回报和损失机制，再研究价格与预期；芒格式反向审查用于检查判断偏差。组合法、成长策略或事件策略可以作为分支，不能把所有思想压进一个统一总分。

## 十 交叉验证和反方审查

交叉验证必须有不同的信息或检验方式。需要分别完成事实核验、经营机制验证、模型合理性检查、反方审查和事后预测验证。几个模型读取同一份材料并得出相近文字，不足以构成独立验证。

反方审查先完整说明最强相反解释和支持证据，再指出它成立时如何损失，以及哪一项观察会使主判断撤回。审查必须能够改变结论。个人模式可将初稿和反方审查作为分开的步骤，但不能因此宣称具有真正独立团队的专业复核。

对已有研报，比较其业务驱动、预测、估值与风险，把差异追到输入、机制或策略。机构声望和目标价数量不能替代证据。若合理模型之间的分歧足以改变决定，报告分歧并补证；只有事前规定且通过样本外验证的组合方法，才可合并预测。

| 检验 | 比较什么 | 失败后的处理 |
| --- | --- | --- |
| 原始证据 | 原文与提取 数值与算术 版本与期间 | 修正数据 撤回受影响结论 |
| 外部经营证据 | 客户 同业 行业或不同测量方法 | 重估原因和持续性 |
| 财务与估值 | 利润现金桥 历史分布 可比及反向条件 | 检查资本投入和隐含假设 |
| 思想与反证 | 能力圈 激励 失败链 机会成本 | 补证 改变策略或停止判断 |
| 前瞻结果 | 事前登记预测与到期结果 相同基准率 | 校准或停用该类预测能力 |

## 十一 结论方向和可信度的表达

正面与负面必须说明相对什么、影响什么、持续多久。事件可能改善收入却压低现金流；公司经营改善也可能已被更高价格反映。结论分别表达商业质量、经营变化、估值回报及账户行动，允许混合、无明显影响或无法判断。

可信度也分开表达。事实质量描述证据是否适用并已核验；解释信心描述机制与替代解释；预测不确定性描述未来结果范围；估值稳健性描述结论对关键假设的敏感程度。投资适宜性另按账户约束判断。不能把这些量折成一个总置信分。科学评估对证据信心与事件发生可能性也作明确区分，此处借鉴区分方式，不移植任何领域的数字等级。[S13]

| 维度 | 可用表达 | 必须附带 |
| --- | --- | --- |
| 事实质量 | 已核验 有限核验 冲突 未核验 | 来源 适用口径 完整性 新鲜度与异常 |
| 解释信心 | 较强 中等 较弱 尚不能解释 | 机制证据 最强反方 关键假设与缺口 |
| 未来预测 | 情景范围 或明确定义事件的概率 | 期限 结算规则 主观或校准状态 |
| 估值稳健性 | 跨可信假设较稳定 或高度敏感 | 决定是否翻转的变量与边界 |
| 决策准备 | 可供审议 有条件 暂缓或退出覆盖 | 尚缺条件 可行动作与复核日期 |

解释信心等级由文字标准和证据理由约束。较强表示关键机制有直接或相互独立的支持、主要替代解释已实质检验，且决定不依赖一个未证实假设。中等表示机制有支持但持续性或规模尚待核实。较弱表示关键暴露、机制或替代解释仍未解决。这些是分析员判断等级，不能解读为统计概率。

如果用户需要数值可信度，系统先明确究竟在预测什么。对尚未经过校准的观点，只能标注主观概率或场景区间；不生成貌似精确的成功率。情景估值区间也不能冒充统计置信区间。

## 十二 概率预测和校准

概率只附在可以结算的事件上。预测创建时固定对象、阈值口径、期限及时区、结算来源、首次登记时间、信息截止点、模型版本、更新原因，以及延期或无法结算的处理。没有合理参考类时展示情景，不强行给概率。

已结算二元事件可采用Brier损失，即对每条预测的概率与实际0或1结果之差求平方，再取平均。还应查看同类概率分组的实际发生频率、样本数和不确定范围，与相同事件、期限和样本上的基准率预测比较。评分规则与校准需要共同评价。[S10]

同一事件每日更新不能算成许多个独立成功样本。评分方案要事前规定初始预测和各期限更新的评价方式；保留未结算、弃权和排除原因，并显示覆盖率。分行业、地区、期限和事件类型评估，防止总体结果掩盖失效类别。

预测准确与投资获利分别检验。一个明确的假设例子是：成功概率80%，成功收益2%，失败损失20%，则未计成本的期望收益为负2.4%。即使概率可信，仍不能据此推出值得买入。

只有积累足够同类、独立、可结算的前瞻记录，才展示经验校准结果；样本不足时明确标记未校准。样本量是否足够取决于事件频率、相关性和要估计的精度，不预设一个保证可靠的统一数量。

## 十三 风险和历史经验的使用

风险审查先解释永久损失、现金履约、融资中断、稀释、治理、估值与被迫出售如何发生。公司能够长期经营，不等于账户能承受中途损失；名义融资额度不等于需要时能到账的现金。波动指标可辅助识别风险，但不能穷尽损失机制。[S6][S7]

每个重点公司至少考虑联合不利情景：经营转弱与估值压缩、现金消耗与融资收紧，或监管变化与供应链中断。逆向压力测试寻找使公司或账户无法承受的条件。模型结果必须显示假设，不能称为最大损失上限。

历史库按脆弱性、触发、传导、可观测警讯、当时不可知信息及处置能力记录。保留失败和退市主体，使用历史股票池与当时公开版本；选择偏差和缺失末期数据会扭曲验证。[S12]

严格区分案例解释、规则回放和预测验证。大模型可能在训练中知道历史结局，即便检索资料设了截止日期，也不能保证没有后见影响。因此历史回放主要检查流程和可复算规则，真正前瞻登记并到期结算的记录承担预测能力验证。

大师的成功案例也存在选择和时代背景。研究库需要失败及反例，检查策略适用条件是否变化；过去有效的倍数、集中度或持有期限不自动成为今天的规则。

## 十四 监测和修改结论

日常监测围绕已有研究判断进行。为每条判断设置关键指标、正常更新频率、支持与反证条件、下一验证、数据过期处理和研究动作。新的重要事实只重开受影响的预测、估值和风险环节，保留旧版本及改变原因。

提醒按潜在决定影响、紧迫性、证据质量与既有暴露排序。事实确定性和影响确定性分别标注。旧消息、转载和已解释的差异不重复推送；小额修订留痕，达到实质影响或存在严重质量问题时升级。具体数值阈值应来自公司指引、历史分布、研究假设或用户风险约束，并记录来源和验证状态。

价格变化触发重新检查市场与经营证据，不单独证明原判断正确或错误。没有新证据并且风险约束未变时，可以保持判断。无关新闻不会自动重写长期研究。

用户可修改假设、撤回结论、退出覆盖或采用不同策略，系统保存理由与影响。不允许删除失败预测以改善成绩，也不允许事后把原来的成长论点改写成资产价值论点。

## 十五 第一版能力和职责

第一版围绕完整研究流程建设。AI可以定位和整理资料、提出竞争解释、生成补证计划及反方检查；确定性财务运算使用可检查的计算关系；重要事实冲突、关键机制选择和账户动作保留人工复核。来源文字只是资料，不能成为改变系统规则的指令。

个人模式的角色是职责区分，而非要求用户组建团队。数据核验、模型计算、反方审查、结论发布和规则修改分别留痕。人工录入同样遵守来源、期间和版本要求；更新失败时在工作台直接呈现。NIST对有效性、解释性及持续评估的区分，可以作为AI能力管理的参考，不把解释清楚等同于判断准确。[S16]

| 第一版能力 | 最小可用结果 | 完成标准 |
| --- | --- | --- |
| 研究立项与假设 | 问题 期限 策略 主假设和反证 | 知道需要什么资料及它会改变什么决定 |
| 证据与获取计划 | 原始来源 状态 依赖 版本和缺口 | 重要陈述可追溯 不把转载算独立证据 |
| 企业与行业档案 | 商业机制 关键指标 财务与风险基线 | 按行业解释 允许超出能力边界 |
| 主动补证与停止 | 有区分力的下一任务及停止理由 | 无法取得关键证据时限制结论 |
| 模型与情景 | 利润现金勾稽 敏感性 估值与隐含条件 | 口径一致 公式可复算 假设显式 |
| 交叉验证与反方 | 替代解释 失败链 分歧及处理 | 审查能够改变结论 有复核记录 |
| 结论与日志 | 分层方向 信心 预测状态 行动和版本 | 允许等待 放弃或不判断 不编造总置信分 |
| 监测与校准 | 相关提醒 日历 数据健康和预测结算 | 旧信息不重复 失败保留 能评价真实前瞻记录 |

首期以少量覆盖对象验证完整流程。扩大实时行情、全市场覆盖、另类数据或复杂模型之前，先证明现有流程的数据、判断与更新能够复核。付费数据采购由关键证据需求决定，不以供应商数量作为成熟度指标。

## 十六 结论的固定交付格式

每份结论采用以下固定内容。读者无需先阅读全部材料，就能知道它回答什么、依据是什么、哪里不确定、什么会推翻它，以及当前可以做什么。完整证据和模型随后展开。

| 内容 | 必须写清 |
| --- | --- |
| 对象与用途 | 公司 行业或证券 决定问题 时间范围 信息截止点 |
| 核心结论 | 商业质量 经营方向 估值吸引力和账户动作分别表达 |
| 重要依据 | 决定性事实及来源 机制与计算 区分管理层说法 |
| 相反解释 | 最强反方证据 主判断为何仍成立或已受损 |
| 结果范围 | 情景及关键假设 概率有无校准 估值敏感点 |
| 可信度 | 事实核验 解释信心 稳健性及各自理由 |
| 缺口与限制 | 关键未知影响哪部分结论 需要补什么 |
| 行动与替代 | 继续研究 等待 放弃 重新研究或有条件投资建议 |
| 失效与验证 | 可观察推翻条件 下一来源 日期或触发事件 |
| 版本与责任 | 本次变化 上次结论 模型与资料版本 人工复核状态 |

合法结论示例  经营方向偏正面，但增量回报尚未得到证据支持；已披露财务事实核验充分，长期回报解释信心中等，估值对利润率高度敏感；当前决定为等待资本回报证据并补充竞争资料。该表达不需要伪造一个上涨概率，也不会因为暂缓而停止所有有效研究。

## 十七 验收和设计完成的边界

此前六家公司提供了数据和机制方面的测试素材：资本投入与会计分类、一次性收益、累计转单季、现金与盈利分化、多地上市和银行专用口径。它们支持设计这些检查项，不构成完整证券结论或预测能力的证明。

设计、实现和验证分别验收。本版已规定研究状态、来源与补证、竞争解释、模型、思想校验、结论与可信度、风险、生命周期和第一版范围。尚未完成的工作是将规则实现为稳定系统，建立授权数据路径，完成不同类型真实研究的前瞻记录与样本外评价。

| 验收案例 | 预期行为 |
| --- | --- |
| 官方数字可靠但原因未证实 | 事实质量可高 解释仍待验证 |
| 很多文章共用一条消息 | 保留共同上游 不增加独立证据数 |
| 关键变量缺失且会翻转决定 | 提出补证任务或暂缓 不产生高信心结论 |
| 情景变化仍支持同一动作 | 给出稳健范围 允许停止补证 |
| 高成功概率但损失不对称 | 分别计算回报和风险 不自动建议买入 |
| 公司改善但证券过贵 | 经营与投资吸引力给出不同方向 |
| 原文和摘要冲突 | 回查原页并阻止受影响的自动更新 |
| 后续资料推翻旧判断 | 撤回或重开 保留旧版和原因 |
| 失败 退市或未结算预测 | 保留记录 解释评分和覆盖范围 |
| 数据源中断或资料过期 | 显式显示 并限制相关结论的时效性 |

评价指标分开报告：证据错误和覆盖、重要事件遗漏、补证有效性、解释与模型可复核性、预测校准及覆盖率、决定对约束的遵守，以及真实投资结果和成本。投资结果好坏不能单独证明研究过程正确，过程合规也不能保证投资获利。
